EMO Tracker Usability Test

Facilitator guide (for the proponents)

Before the session

  1. Use the MacBook with the demo data in its separate demo database (README, "Resetting Demo Data"). Reset it right before each session, so every user starts with the same data. Never run the test on the EMO's real schedule.
  2. Put the sample file Program flow.pdf on the MacBook's Desktop (needed for task 9).
  3. Prepare a stopwatch (a phone is fine) and one task sheet for the user's role. Demo password for every account: password123.

Say this at the start

"Thank you for helping us. We are testing EMO Tracker, not you, so there are no wrong answers. I will read some tasks one at a time. Please do them as you normally would and say out loud what you are thinking. I can't help you during a task unless you're stuck. After each task, I'll ask you one quick question."

For each task

  1. Read the task aloud, then start the stopwatch.
  2. Don't help. If the user asks for help or is stuck for 3 minutes, help them, and mark With help.
  3. Stop the stopwatch when the expected result appears, or when the user gives up (mark No). Write the time in seconds (1 min 30 s = 90).
  4. Ask: "From 1 to 5, where 1 is strongly disagree and 5 is strongly agree: this task was easy to do." Circle the number.
  5. Write anything that confused the user in Notes.

After all tasks

  1. Ask the two closing questions on the task sheet and write the answers.
  2. Give the SUS questionnaire, then the ISO/IEC 25010 questionnaire. The user answers them alone.
  3. Write the same Respondent No. on all three forms. After the last session, set DB_DATABASE in backend/.env back to emo_tracker.
