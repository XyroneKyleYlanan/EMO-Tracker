API Endpoint Documentation — EMO Tracker

How to use: Select the table, copy (Ctrl+C), and paste into Word or Google Docs. It pastes as an editable table. Generated from the system's route list on October 10, 2026: 42 endpoints (45 route registrations; "PUT / PATCH" rows accept either method).
For every endpoint: requests and responses are JSON (except file downloads); every endpoint except login and ping needs the login token (Authorization: Bearer <token>); a missing or expired token returns 401, a role that isn't allowed returns 403, and invalid input returns 422 with the reason. The server also refuses non-admin changes to a completed event's tasks (403).

#MethodEndpointWho can use itWhat it does
Login and account
1POST/api/loginPublic (limited to 10 tries a minute per email and device)Sign in with email and password. Returns a login token (valid for 30 days) with the user's name and role.
2POST/api/logoutAny signed-in userSign out on this device (deletes its token).
3GET/api/meAny signed-in userThe signed-in user's name, email and role.
4POST/api/change-passwordAny signed-in userChange one's own password; signs out the user's other devices.
5GET/api/pingPublicCheck that the server is running.
Home pages
6GET/api/dashboard/adminAdministratorThe Administrator's Home: summary, events that need attention, the next 7 days and the backup status.
7GET/api/dashboard/officerAdministrator, OfficerThe Officer's Home: summary, events that need attention and the next 7 days.
8GET/api/dashboard/staffStaffThe Staff Home: the user's open tasks, upcoming events and summary.
Events and Schedule
9GET/api/eventsAny signed-in userList events with their readiness. Options: status, prepared (EMO-prepared only), mine (only events where the user has tasks).
10GET/api/events/{event}Any signed-in userOne event with its tasks, documents, creator, venue and any overlapping bookings.
11POST/api/eventsAdministratorAdd an event. Its status is set from its date.
12PUT / PATCH/api/events/{event}AdministratorEdit an event: details, cancel or restore, and mark a date change as a reschedule.
13DELETE/api/events/{event}AdministratorDelete an event with its tasks and documents.
14GET/api/event-clashesAdministratorCheck a venue, date and time for overlapping bookings (used by the event form while it is filled in).
15GET/api/departmentsAdministratorDepartment names already in use, as suggestions for the event form.
16GET/api/scheduleAny signed-in userOne year of the Schedule (option: year), with overlaps marked.
17GET/api/schedule/exportAdministrator, OfficerDownload one year of the Schedule as an Excel file (option: year).
Venues and buildings
18GET/api/venuesAny signed-in userAll venues and buildings, with how many events use each venue.
19POST/api/venuesAdministratorAdd a venue.
20PUT/api/venues/{venue}AdministratorRename a venue or change its building.
21DELETE/api/venues/{venue}AdministratorDelete a venue. Refused if events use it (merge it instead).
22POST/api/venues/{venue}/mergeAdministratorMerge a duplicate venue into another: its events move to the other venue.
23POST/api/buildingsAdministratorAdd a building with a color.
24PUT/api/buildings/{building}AdministratorRename a building or change its color.
25DELETE/api/buildings/{building}AdministratorDelete a building. Its venues stay, without a building.
Tasks
26GET/api/events/{event}/tasksAny signed-in userAn event's tasks.
27POST/api/events/{event}/tasksAdministrator, OfficerAdd a task with an owner, due date and priority.
28PUT / PATCH/api/tasks/{task}Administrator, OfficerEdit a task. On a completed event, only the Administrator can.
29DELETE/api/tasks/{task}Administrator, OfficerDelete a task. On a completed event, only the Administrator can.
30PATCH/api/tasks/{task}/statusAny signed-in user (Staff: own tasks only)Change a task's status (Pending, In progress or Done).
31GET/api/my-tasksAny signed-in userThe tasks assigned to the signed-in user.
Documents and reports
32GET/api/events/{event}/documentsAny signed-in userAn event's documents.
33POST/api/events/{event}/documentsAdministrator, OfficerUpload a document (PDF, Word, Excel, JPG or PNG, up to 10 MB) to private storage.
34GET/api/documents/{document}/downloadAny signed-in userDownload a document.
35DELETE/api/documents/{document}AdministratorDelete a document and its file.
36GET/api/events/{event}/reportAny signed-in userDownload the event's PDF report.
Analytics
37GET/api/analyticsAdministrator, OfficerSchedule and preparation statistics for a period (option: period = week, month, year or all).
Accounts
38GET/api/usersAdministrator, OfficerList accounts (options: role, is_active). Officers use it to choose task owners.
39POST/api/usersAdministratorCreate an account with a name, email, password and role.
40GET/api/users/{user}AdministratorOne account.
41PUT / PATCH/api/users/{user}AdministratorEdit an account: name, email, role, new password, or reactivate it.
42DELETE/api/users/{user}AdministratorDeactivate an account and sign it out everywhere. Accounts are never deleted.
