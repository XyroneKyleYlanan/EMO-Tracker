How to use: Select a table, copy (Ctrl+C), and paste into Google Docs or Word. Same layout as the Capstone 1 appendix. All 42 endpoints of the system (45 route registrations; "PUT / PATCH" rows accept either method), checked against the system's route list on October 10, 2026; parameters and responses were read from the code.
For every endpoint: all paths start with /api (for example, /api/login); requests and responses are JSON, except file downloads; "Yes" in the Auth column means the request must carry the login token (Authorization: Bearer <token>). 401 means a missing, expired or revoked token (including a deactivated account's); 403 means the user's role may not use the endpoint; 404 means the item no longer exists; 422 responses include the reason for each invalid field.
