Data Dictionary — EMO Tracker

How to use: Select a table below, copy it (Ctrl+C), and paste into Word or Google Docs. It pastes as a native, editable table.
Checked against the database on October 7, 2026. These are the system's 7 application tables. Laravel's own housekeeping tables (personal_access_tokens, sessions, cache, cache_locks, jobs, job_batches, failed_jobs, password_reset_tokens, migrations) aren't listed.

Table: users

Stores all user accounts, roles, and authentication data.

Field NameData TypeConstraintDescription
idbigint unsignedPrimary Key, Auto-incrementUnique identifier for each user
namevarchar(255)NOT NULLFull name of the user
emailvarchar(255)NOT NULL, UniqueEmail address; used as the login credential
email_verified_attimestampNullableSet when an administrator creates the account (Laravel default; not used for login)
passwordvarchar(255)NOT NULLHashed password (bcrypt, 12 rounds); never stored as plain text
roleenum('admin','officer','staff')NOT NULL, Default 'staff'Determines the user's access level
is_activebooleanNOT NULL, Default trueIf false, the account cannot log in and is signed out everywhere. Accounts are deactivated, never deleted
remember_tokenvarchar(100)NullableToken for persistent login sessions (Laravel default)
created_attimestampNullableRecord creation timestamp
updated_attimestampNullableRecord last-update timestamp

Table: events

Stores every event and venue booking on the schedule, whether or not the EMO prepares it.

Field NameData TypeConstraintDescription
idbigint unsignedPrimary Key, Auto-incrementUnique identifier for each event
namevarchar(255)NOT NULLName/title of the event
descriptiontextNullableDetailed description of the event
departmentvarchar(255)NullableRequesting department, or the organizer for external events
event_typeenum('internal','external')NOT NULL, Default 'internal'Internal: an NEU event. External: organized by an outside person or group
venue_idbigint unsignedForeign Key → venues(id), Nullable, set null on deleteThe venue from the managed venue list
venue_detailsvarchar(255)Nullable; required when no venue is chosenRoom or details within the venue, or the place for unlisted locations
event_datedateNOT NULLStart date (first day) of the event
end_datedateNullable; not before event_dateLast day of a multi-day event
event_timetimeNullableStart time (empty if not yet announced; no time means all day)
end_timetimeNullable; on a one-day event, must be after event_timeEnd time
original_datedateNullableFirst scheduled date of a rescheduled event; empty if it was never moved
original_timetimeNullableFirst scheduled start time of a rescheduled event
control_numbervarchar(255)NullableThe EMO's control number for the booking
remarkstextNullable; up to 2,000 charactersFree-text notes
needs_preparationtinyint(1)NOT NULL, Default 0Whether the EMO prepares the event (turns on readiness tracking; switched on automatically when a task is added)
statusenum('upcoming','completed','cancelled')NOT NULL, Default 'upcoming'Upcoming until the event ends, then completed (automatic); cancelled is set by an administrator and can be undone. "Ongoing" isn't stored: it's an upcoming event that has started
created_bybigint unsignedForeign Key → users(id), NOT NULL, cascade on deleteThe user who created the event (users are deactivated, never deleted)
created_attimestampNullableRecord creation timestamp
updated_attimestampNullableRecord last-update timestamp

Table: tasks

Stores tasks belonging to events, including assignment and progress.

Field NameData TypeConstraintDescription
idbigint unsignedPrimary Key, Auto-incrementUnique identifier for each task
event_idbigint unsignedForeign Key → events(id), NOT NULL, cascade on deleteThe event this task belongs to (deleted together with the event)
namevarchar(255)NOT NULLName/title of the task
descriptiontextNullableDetailed description of the task
due_datedateNOT NULLDate the task is due (may fall after the event; the form warns)
statusenum('pending','in_progress','done')NOT NULL, Default 'pending'Current progress status of the task
priorityenum('low','medium','high')NOT NULL, Default 'medium'Priority level of the task
assigned_tobigint unsignedForeign Key → users(id), Nullable, set null on deleteThe task's one owner: any active member, whatever their role; null if unassigned
created_attimestampNullableRecord creation timestamp
updated_attimestampNullableRecord last-update timestamp

Field NameData TypeConstraintDescription
