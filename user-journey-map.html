User Journey Map — EMO Tracker

How to use: Select a table below, copy (Ctrl+C), and paste into Word or Google Docs — it pastes as a native, editable table. Each map traces one role's experience across the stages of using the system (updated October 7, 2026).
Note: the Expected Emotion column describes the intended experience. Confirm or revise it with EMO users during the pilot.
