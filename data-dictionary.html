Table: users

Stores all user accounts, roles, and authentication data.

Field NameData TypeConstraintDescription
idbigint unsignedPrimary Key, Auto-incrementUnique identifier for each user
namevarchar(255)NOT NULLFull name of the user
emailvarchar(255)NOT NULL, UniqueEmail address; used as the login credential
email_verified_attimestampNullableEmail verification timestamp (Laravel default; unused)
passwordvarchar(255)NOT NULLHashed password (bcrypt)
roleenum('admin','officer','staff')NOT NULL, Default 'staff'Determines the user's access level
is_activebooleanNOT NULL, Default trueIf false, the account cannot log in
remember_tokenvarchar(100)NullableToken for persistent login sessions (Laravel default)
created_attimestampNullableRecord creation timestamp
updated_attimestampNullableRecord last-update timestamp

Table: event_staff

Junction table linking events to staff assigned at the event level (many-to-many).

Field NameData TypeConstraintDescription
idbigint unsignedPrimary Key, Auto-incrementUnique identifier for each assignment record
event_idbigint unsignedForeign Key → events(id), NOT NULLThe assigned event
user_idbigint unsignedForeign Key → users(id), NOT NULLThe assigned staff member
created_attimestampNullableRecord creation timestamp
updated_attimestampNullableRecord last-update timestamp

Note: event_id + user_id together form a composite UNIQUE constraint to prevent duplicate assignments.
